# Sistema de Gestión y Análisis de Inventario

## Descripción
Proyecto académico de diseño e implementación de una base de datos relacional para gestionar productos, categorías, clientes y pedidos.

## Tecnologías
- **SQLite y SQL:** diseño, relaciones y consultas de base de datos.
- **Python y Pandas:** conexión, procesamiento y análisis de información.
- **Google Colab:** entorno de desarrollo.

## Funcionalidades
- Consulta y gestión de inventario.
- Detección de productos con stock bajo.

## Modelo de datos
Cinco tablas relacionadas: categorías, productos, clientes, pedidos y detalle de pedido.
